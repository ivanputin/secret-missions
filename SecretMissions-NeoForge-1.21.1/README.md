# Secret Missions — NeoForge 1.21.1

Исходный проект для **Minecraft 1.21.1 / NeoForge 21.1.x / Java 21**, только одиночная игра (интегрированный сервер).

## Правила

- 10 миссий на забег, **по одной из каждой из 10 категорий**, случайный порядок.
- 60 заранее написанных вариантов (6 на категорию).
- Следующая миссия скрыта до выполнения предыдущей.
- **M** — открыть интерфейс (клавишу можно изменить в управлении).
- Автоматический учёт действий: разрушение/установка блоков, крафт, убийства, биомы, пройденное расстояние, предметы в инвентаре, время без урона, урожай, встреченные животные.
- Кнопка «Новый забег» требует второго нажатия для подтверждения. **Старый прогресс будет сброшен.**
- Сохранение в `world/data/secretmissions_progress.dat` средствами SavedData.
- События до открытия миссии не засчитываются, кроме задания «держи в инвентаре», которое проверяет текущее состояние инвентаря.

## Как собрать

1. Установи JDK 21 и IntelliJ IDEA.
2. Распакуй ZIP, открой папку как Gradle-проект.
3. Требуется интернет для первой загрузки Gradle и зависимостей NeoForge.
4. Если Gradle уже установлен: `gradle build`. Если нет — добавь официальный Gradle Wrapper из шаблона [MDK 1.21.1 ModDevGradle](https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle) или используй установленный Gradle 8.10.x.
5. Готовый JAR появится в `build/libs/` и помещается в папку `mods` установки NeoForge 1.21.1.

## Важные замечания

- **Сборка и запуск в Minecraft здесь не проверены:** в среде подготовки нет скачанных Gradle/NeoForge-зависимостей и сетевого доступа. Возможно, потребуется небольшая адаптация к конкретной сборке NeoForge.
- Проект рассчитан на одиночную игру, клиентское меню читает данные встроенного сервера напрямую; для мультиплеера потребуется синхронизация пакетами.
- Таймер задания «без урона» сбрасывается при получении урона. Время игры и прогресс хранятся в мире.
- На экране отображается только название уже выполненных миссий и описание текущей; будущие миссии скрыты. Исходный код, разумеется, содержит полный список.
- Некоторые задания (например, посещение редкого биома) могут оказаться долгими; новый забег позволяет сменить условия.
