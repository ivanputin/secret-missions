# Бесплатная сборка без установки IDE

**Внимание:** исходники не прошли компиляцию в среде создания архива (не было доступа к загрузке зависимостей). Если GitHub Actions сообщит об ошибке компиляции, скопируйте лог ошибки разработчику — скачанный исходный архив НЕ является готовым работающим .jar.

1. Создайте бесплатный аккаунт GitHub (github.com), если его нет.
2. Создайте новый публичный репозиторий, например `secret-missions`.
3. Распакуйте архив и загрузите **содержимое папки** `SecretMissions-NeoForge-1.21.1` в корень репозитория, сохраняя папку `.github/workflows/`.
4. Перейдите в GitHub → Actions → Build NeoForge mod JAR → Run workflow. При `push` на `main` сборка тоже запускается автоматически.
5. Если сборка завершилась зелёной галочкой, откройте её страницу, в разделе Artifacts скачайте `SecretMissions-NeoForge-1.21.1-JAR`.
6. Распакуйте архив артефакта; поместите **только собранный `.jar`** из него в `.minecraft/mods`.
7. Запускайте Minecraft Java Edition **1.21.1 с NeoForge 1.21.1**.

GitHub Actions предоставляет бесплатные минуты для публичных репозиториев в пределах стандартных условий сервиса. Бесплатны также Java 21, Gradle, Git и IntelliJ IDEA Community.

Не переименовывайте `.zip` в `.jar`: это не превращает исходники в мод.
